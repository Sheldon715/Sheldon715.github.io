  1. 01

    Decision routing

    An LLM classifies each request on Supabase Edge Functions and routes it across five product capabilities, with cost and latency logged for every decision and row-level security protecting user data.

  2. 02

    Evaluation-gated model choice

    A 241-message evaluation set compared models on routing accuracy, safety, latency and cost; every prompt-injection test passes at about 620 ms P95.

  3. 03

    People Discovery

    Natural-language search for creatives that combines keyword and pgvector retrieval with an LLM relevance layer to filter and rank candidates—under 2.4 s P95 on 50 unseen queries, run 3 times each.

  4. 04

    Grounded Q&A

    An in-app assistant that answers only from a curated knowledge base, with navigation limited to approved screens, checked across 211 blind-evaluated questions.

  5. 05

    Flutter product surfaces

    Multi-conversation chat, AI-assisted onboarding, job-post drafting and content suggestions, implemented end to end and test-first.
